# Proyecto Integrador - Programación Orientada A Objetos.

Herramientas utilizadas (Links directos para descargar)

SQLite para x64
https://sqlite.org/2026/sqlite-tools-win-x64-3540100.zip
1-Descomprimir la carpeta.
2-Ejecutar el archivo "sqlite3".

Browser (Interfaz visual para sqlite) x64
https://github.com/sqlitebrowser/sqlitebrowser/releases/download/v3.13.1/DB.Browser.for.SQLite-v3.13.1-win64.msi
1-Instalación predeterminada.

IDE utilizada IntelliJ
https://www.jetbrains.com/es-es/idea/download/download-thanks.html?platform=windows
1-Instalación predeterminada.

Dentro de nuestra IDE tenemos que tener instalada la extensión Swing UI Designer 
1-Dentro del IDE presionar Crtl + Alt + S.
2-Entrar en Plugins.
3-Buscar Swing UI Designer e instalarlo.
4-Cerrar y volver a abrir el IDE.
